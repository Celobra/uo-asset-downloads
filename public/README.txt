UO WORKSHOP - DOWNLOAD AND PREVIEW NOTES

CHOOSING A DOWNLOAD
Open an asset listing to read its formats, requirements and integration status.
Use Game files for the supplied native assets, import files, scripts or layouts.
Contents differ between projects; read the instructions and checksums inside
that package before importing it.

GIFs, images and the interactive viewer are previews. They show appearance and
motion but do not install an asset or supply missing animation actions. Actual
playback, equipment layering and gameplay depend on the receiving client and
server. A preview speed is not a promise of native game timing.

SETS, PIECES AND VISIBILITY
Where a collection offers a full set or individual pieces, use its download
selector to choose the package you want. The piece checkboxes, Full set and
Clear controls change the displayed preview. They do not change the contents
of the prepared downloads or create a new combined package.

IMPORTING INTO YOUR PROJECT
Use compatible, current client data and the server required by the package.
Work on a separate development copy first and keep a recoverable backup.
Follow the supplied installation instructions; inspect destination IDs and
existing mappings before choosing free space or replacing an occupied record.
An ID used by a package example is not proof that it is free in your files.

Review the proposed client files, scripts and destinations before saving.
Some assets need additional client integration or server behaviour. Check
required actions, directions and wearable movement or riding coverage, then
test the result on the receiving client and shard. A successful import alone
does not establish gameplay correctness or visual fit.

UO ASSET STUDIO AND THE COMPLETE GUIDE
Studio opens Home before folder setup. Direct animation-to-VD conversion can
write a separate file immediately; link your client and server folders when
you begin an import or script workflow. Simple mode supplies defaults for
supported imports. Advanced exposes manual choices, and hover help explains
the controls. Both modes keep preview and save review available.
