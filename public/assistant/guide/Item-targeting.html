Choose the object in your game.

Point at an item, bag, vendor or place when setting up your assistant. The selected details return to the tool you opened.

Getting started · User guide · Release notes

Add a loot or scavenger item

  1. In the assistant, open Items / Loot / Loot & scavenging.
  2. Choose Loot or Scavenge in Rule library, then choose the set to edit.
  3. Choose Target item to add, return to the game and click the item.
  4. The tool saves a rule using that item's observed type and colour. Read the saved rule in the selected set. A matching rule is reused instead of added twice.

For an empty library, a default set is created after a valid item selection. Cancelling does not create an empty set.

This button saves a rule. It does not loot the selected item, move anything or start a loot/scavenger watch. Review your set before using Preview or Run.

Choose the loot bag

  1. Open the destination bag in game so the assistant can observe it.
  2. Choose the Loot or Scavenge set, then choose Target loot bag.
  3. Click the bag in the game. A valid accessible container becomes the saved destination for that set.

The source and destination cannot be the same container. A refused selection leaves the saved destination intact. Use Target item to protect when you want to save an exact item as protected; this does not protect every item of its type.

Add a vendor rule

  1. Open Items / Vendors and the buy/sell rule library.
  2. Choose the set and review the visible quantity, price and keep limits.
  3. Choose Target item to add and click the item in the game. The saved rule uses its type and colour together with those limits.
  4. To save a vendor, open the matching buy or sell quote in game first, then choose Target vendor and click that vendor.

Selection does not buy or sell. The vendor must match the currently observed quote. Review the saved rules and the quote before starting a trade.

Fill another form from the game

Use the selection button beside an object, container, type, colour or position field. Click the intended game object or place, then review the fields that were filled. The status message names the next Add or Save action when one is required.

What you chooseWhat to review
An exact object or containerThe name and object identity. Open bags first; an item must be observed and suitable for that field.
An item type or colourThe selected item's type and colour. A type rule may match other items with the same details.
A ground positionThe coordinates and current facet. Macro and walking fields store XYZ; map and travel presets also retain the selected facet. Choosing a location does not start walking, travel or resource work.

Quick loot/vendor buttons save their stated definition directly. Inventory's Pick and add counter in game, exact equipment selection and use-once exact-item selection also add or save directly. Field pickers fill the open form for review. Read the button and status message to see whether a further Add or Save is needed.

More places to use selection

  • Organizer & restock: choose source/destination containers and pick an organizer or restock item type, then finish the rule with its Add/Save action.
  • Equipment and crafting: choose an exact equipped item or fill an equipment selector; select a crafting tool or ingredient. Use the loaded crafting dialog and captured reply controls for dialog/button details.
  • Macros and Simple steps: pick a step object, destination, use-type item or ground position. Loaded dialog/button controls copy observed dialog details; they do not open a dialog or press its buttons.
  • Hotkeys, input bindings and action bars: fill an object action from the intended game object, then save the binding.
  • Walking and runebooks: pick destinations, books, resources and arrival locations. Review the filled values and save the definition before starting a task.
  • Map and recovery: pick-and-save marker, healer, route waypoint and return-point actions retain that location directly. Zone vertices and coordinate origins fill drafts for their existing Save actions.

Amounts, delays, limits, spell IDs and skill IDs remain settings you choose. Selecting an object supplies its observed game details; it does not decide your task's quantity or timing. A potion-type selection cannot prove that an item is an ordinary, non-throwing potion; verify it before saving convenience settings.

Cancel or try again

Press Escape in the game to cancel its selection cursor. An unavailable, cancelled, timed-out, stale or unsuitable selection leaves saved definitions intact. Read the assistant's status message, correct the reason and select again.

Keep the paired game connected while choosing. Reconnecting, changing profiles or closing the tool can invalidate a pending selection. Only one selection cursor can be answered at a time. If a server action already needs a target, finish or cancel it before setting up another assistant field.

Game selection uses currently observed facts. It does not discover the contents of unopened bags or confirm that a server action succeeded. Manual numeric fields and the advanced editors remain available where provided.

Before updating and testing

Close this application's launcher, assistant and game before installing 0.7.1. Setup replaces identified earlier installations and retains saved profiles, scripts and user-added files. No game assets, accounts or private profiles are included.

This unsigned Windows x64 preview is checked with synthetic game and interface fixtures. Test a short selection, preview and action on your shard before relying on a saved rule. Server permissions, shard-specific objects and live gameplay still need manual checks.

The detailed PDF reference manuals included with this package keep their 0.7.0 edition. Use this HTML guide for the new selection workflow.
