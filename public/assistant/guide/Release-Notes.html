UO Assistant 0.6.0

Categories, clearer controls and safer editing.

What changed

Eight categories with tabs replace the long feature list: Home, Character, Items, Tasks, Map & travel, Controls, Recording and Settings. Existing tools, favorites and advanced scripting remain available.

A shared task library brings Simple Scripts, JavaScript, macros and workflows together. Task-word search, named object choices and an advanced-tools switch help new users find the right controls.

Simple and JavaScript drafts survive script selection and page rebuilding. Save all validates drafts together; closing offers save, discard or cancel. Custom run limits display their exact number of seconds.

Failed legacy edits roll back instead of leaving partial changes in the live profile. Task shortcuts retain a stable identity through renaming and reject ambiguous legacy names.

Walking, use-once items, target presets and keyboard/mouse bindings now have focused pages. Game action recording remains distinct from video/replay recording.

Accessible editor labels, a compact fixed window frame, pinned actions, a recent-activity window and known inventory names improve everyday use. Disconnected closing no longer re-enters the same close event.

The updated guides include a six-page getting-started manual, 22-page beginner scripting manual and 85-page complete scripting reference. The advanced JavaScript API and all 15 beginner recipes are retained.

Verification and limits

1,306 application checks, including 276 interface checks, cover existing behavior and the audit regressions. Launcher, installer, source and website verification are recorded separately.

Unsigned Windows x64 development preview. Tests use synthetic game state. Live Invicta harvesting, shard-specific graphics/dialogs and populated-world performance still need receiving-system checks. Fresh install/uninstall was not repeated because the existing installation was preserved. Drafts are held in memory, not a crash-recovery file. External Qodo review was unavailable because the CLI was signed out; local review is not independent approval. Recording dependencies and their hardware limits are unchanged from 0.3.0.
