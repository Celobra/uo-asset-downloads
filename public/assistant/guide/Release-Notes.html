UO Assistant 0.1.6

14 October 2026 · Windows x64 · unsigned development preview

Getting started · Assistant tools · Third-party notices

New cooldown tracker

  • Editable potion, bandage and custom countdowns in the separate assistant, with fractional-second durations.
  • Manual start/reset, observed owned-item use requests, and configurable literal journal messages.
  • Optional ready-message completion; active item-use countdowns ignore repeated requests.
  • Saved definitions are separate for each shard profile and included in assistant backups. Temporary running countdowns are not saved.
  • Passive tracking and a dashboard summary; countdowns do not send gameplay actions or change shard cooldown rules.

Starter durations and messages are examples to adjust for your shard. Automatic tracking is disabled for these rows until you choose to enable it. Item-use timers show estimates because requesting an action does not establish that the shard accepted it.

Retained behavior

The full GPU client handles movement, gumps, clicks, targeting and networking. The assistant opens in a separate window; closing either closes its paired application. The CPU/Draw FPS display, agent tools, counters, scripts, macros, maps, filters and backups are retained. Rendering cadence is unchanged.

Installation

Per-user installation includes the launcher, client, assistant and app-local .NET 10.0.12 runtimes. The desktop shortcut is optional. Private profiles are outside the installation and remain after uninstall. The installer contains no game assets, accounts, saves, credentials or private logs.

Verification

The underlying earlier GPU gameplay was accepted in manual testing. This update's timing, persistence, passive observation and packaging checks are recorded separately; they do not certify timing rules for every shard. New triggers and durations still need a manual check against your shard's messages and behavior.
