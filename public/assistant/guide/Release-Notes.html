UO Assistant 0.5.0

Simple Scripts for beginners. Unsigned Windows x64 development preview.

What changed

Simple Scripts is a new beginner mode alongside the unchanged JavaScript editor. Choose a recipe, add steps with menus, check the whole source, save and run explicitly.

Readable commands cover named spells and skills, automatic target waits, items by name/graphic/hue/saved object, container moves, equipment, walking, tree/cave/tile scanning, window and journal interactions, conditions and finite loops.

The Add a step builder provides 43 entries and fifteen complete starter recipes. Choose an object saves a memorable name. Make an advanced JavaScript copy retains a separate editable translation.

The Invicta nearby-tree recipe is one command, with its established finite runtime, weight, health, tool and journal checks. Unreachable trees are reported as skipped. No banking or ground dropping is added.

.uosimple import/export and library backups preserve the language; portable Simple files also retain their run limit. Older scripts default to JavaScript, without automatic rewrites.

The 21-page beginner manual, 84-page complete scripting manual, HTML guides and standalone recipes accompany the unchanged 48-method JavaScript SDK.

Verification and limits

The actual Jint engine and packaged WPF interface are tested with synthetic state, including unknown names, target waits, multi-stack moves, incomplete scans, movement failures, stopped runs and old JavaScript compatibility. Runtime, installer, source and download hashes are checked during publication.

Names and tiles come from currently loaded client facts. Custom graphics and shard messages can differ. Automated tests use synthetic game state; live Invicta harvesting and receiving-system gameplay remain manual checks. The existing 0.3.0 installation and game data were preserved, so a fresh install/uninstall was not repeated. The installer is unsigned. External Qodo review remains unavailable because the CLI is signed out. Existing recording dependencies are unchanged; corresponding FFmpeg sources and rebuild archives remain in release 0.3.0.
