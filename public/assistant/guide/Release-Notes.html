UO Assistant 0.2.1

16 October 2026 - Windows x64 - unsigned development installer

Getting started · Automatic updates · All features · Scripting manual

Automatic checks at www.uoassets.com

  • Fresh launcher preferences automatically check the UO Assistant website feed in the background.
  • A visible update notice opens the release details when a newer version is available.
  • Startup and periodic checks are bounded, cannot overlap and cancel when the launcher closes. Play remains available while checking or offline.
  • Existing saved opt-outs and custom feeds are preserved. Updates & recovery provides manual checking and the automatic-check setting.
  • Large installers use signed, version-specific GitHub download addresses and restricted HTTPS redirects. Exact size, hash, signature and application identity are verified.
  • Downloading and installation are explicit choices. Installation requires the game and assistant to be closed, and backs up assistant definitions.

Gameplay preserved

This is a launcher update. The game client, renderer and separate assistant use the exact same sealed program bytes as 0.2.0. All existing expanded assistant tools and the CPU/FPS display remain. Closing the assistant closes its paired client, and vice versa.

Guide and examples

The scripting API is unchanged, so the supplied 0.2.0 scripting manual and twelve examples remain applicable. Read the update addendum for the new launcher defaults and website behaviour.

Development status

The installer remains unsigned for Windows publisher identity. Release-catalog signatures are separate application integrity checks. No game assets, accounts, saves or private settings are included. Earlier releases remain available. Shard-specific tools and timing rules still need a manual in-game test.
