UO Assistant 0.4.0

Read-only scanning for terrain, items and open game windows. Unsigned Windows x64 development preview.

What changed

  • scanTiles: nearby loaded land and statics, tree/cave classification, name/graphic/hue filters, original and seasonal art IDs, bounded pages and explicit missing-data flags.
  • findItems: cached property/item/tile names, graphics, hues, ownership, ground range, equipment and recursive container filtering.
  • findGumps: visible local and server windows, active-page nested controls, text, artwork and button metadata. Editable fields are excluded; scanning does not grant reply authority.
  • Explicit script limits up to 1800 seconds, with finite scaled execution budgets. The default remains 60 seconds.
  • 48-method SDK, 15 standalone examples and updated 64-page scripting manual. The offline bench refuses terrain and general gump queries when it has no such data.

Verification

399 native client tests, 227 automation checks, 22 scanning checks, 30 protocol checks, 30 library checks, 45 native tools checks, 72 maps/travel/team checks, 78 workflow checks and 195 synthetic assistant interface checks passed. The separate harvesting script passed 26 simulated scenarios and two actual Jint scenarios. No live game inputs were sent.

Installer payload and source hashes are verified during packaging. A fresh install/uninstall test was not run because the product is already installed on the test machine; its existing registration and game data were preserved. External Qodo review is unavailable because the CLI is signed out.

Limits

Scans report loaded facts, not hidden shard data. Custom graphics and translated names can require explicit filters. Large or changing windows and unloaded terrain produce partial results. Native scan time budgets are cooperative, not real-time guarantees. Live shard harvesting and populated-world performance remain manual acceptance checks.

The existing recording libraries are unchanged. Their exact binary, FFmpeg source/rebuild and dependency-source archives remain available with release 0.3.0. All notices and modification/recombination rights remain in the installer and source kit.
