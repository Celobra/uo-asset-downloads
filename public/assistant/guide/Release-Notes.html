UO Assistant 0.6.1

Updates replace earlier installed copies.

What changed

Setup identifies earlier UO Assistant installations and runs their own uninstallers before installing the new version. It checks Windows registrations, the selected destination and named UO Assistant folders under the current user's Programs folder, including identifiable copies whose Windows registration is missing.

Setup checks all discovered locations before removing anything. Close the launcher, assistant and game first. A running app, incomplete uninstall or damaged installation stops the update with an explanation. Linked folders, copied uninstall logs and unrelated destinations are refused.

Saved profiles and scripts remain outside installed program files and are retained. Files added by the user that are not owned by the installer are retained too. Downloads, portable copies and development folders are not automatically deleted. An older all-users installation needs removal through Windows Installed apps if this per-user setup cannot remove it.

The eight categories, Simple Scripts, advanced JavaScript and game client are unchanged from 0.6.0.

Verification and limits

18 real installer lifecycle checks use a unique test identity and isolated folders: duplicate older installs, removal failure, locked files, preservation, repeated updates and final uninstall. They do not change an existing game installation or use personal profiles. Launcher and package checks are recorded separately. The unchanged 0.6.0 client retains its prior 1,306 synthetic application checks; those application tests were not rerun for this installer patch.

Unsigned Windows x64 development preview. Live shard and receiving-system checks remain necessary. Qodo review was unavailable because its CLI is signed out; local review is not independent approval. Recording binaries and corresponding dependency archives are unchanged from 0.3.0.
