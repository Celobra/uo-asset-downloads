Automatic update checks

The launcher checks the website for updates. Version 0.6.1 also removes identified older installations before installing the replacement. Your game and separate assistant continue to use the verified GPU client.

Getting started · Release notes · Scripting manual

How it works

  1. Open the launcher. A new installation checks www.uoassets.com in the background.
  2. If a newer version is available, use the update notice to review its release notes and download.
  3. The launcher verifies the release signature, exact installer size, checksum and application version.
  4. Close the game and assistant when ready, then choose Install. Your assistant definitions are backed up before installation starts.

Checks do not interrupt Play, log in, send game actions or close an active session. An unavailable website leaves the launcher usable. Downloading and installation remain explicit choices.

Control update checks

Open Updates & recovery. Turn automatic checks off if you prefer, or choose Check feed now whenever needed. Existing saved opt-outs are retained. The default feed is https://www.uoassets.com/assistant/update.json.

The launcher can check again while it remains open. Checks have a bounded timeout and cannot overlap. Closing the launcher cancels its background checks. A check never installs software automatically.

Downloading and recovery

The small release feed is hosted on the website. Large installers use the project's versioned GitHub Releases downloads. HTTPS redirects are restricted to supported hosts and bounded, and the final bytes must match the signed release record.

Older verified versions remain available for recovery where supplied. Review the older-version checkbox and its rule compatibility notes. Private profiles remain outside installed program files and are retained after uninstalling.

This development installer remains unsigned for Windows publisher identity. The application release signature used by the updater is a separate integrity check.

One installed copy after an update

  1. Download the update from the launcher or website.
  2. Close the launcher, assistant and game, then open the installer.
  3. Keep the existing application folder unless you need to move it. Setup checks earlier copies, runs their uninstallers and then installs this version.
  4. Open UO Assistant as usual. Your saved profiles, scripts and update preferences are retained.

Setup checks Windows registrations, the selected folder and UO Assistant folders directly under your personal Programs folder. It also recognizes an earlier installation there when its Windows registration is missing. Downloaded installers, portable copies and development folders are not deleted.

If setup cannot remove an earlier copy

Close any running UO Assistant windows and try again. If setup reports missing or damaged uninstall files, repair that installation or remove it through Windows Settings → Apps → Installed apps. An older copy installed for all Windows users may need administrator permission to remove. Setup stops before installing a duplicate when removal cannot finish. If Windows requests a restart, restart before trying again.

Files you added yourself are left in the old folder. Saved profiles and scripts in the separate UOAssistant user-data folder are kept. The installer does not follow linked folders into profiles or shard data.
