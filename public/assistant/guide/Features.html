Keep movement, gumps and targeting in the game. Configure information, shortcuts, maps and checked tasks in the assistant beside it.

The two windows open together and close together. No command window opens during normal startup. Scripts, observers, healing watches, capture and external team sharing wait for your explicit start. Use your shard's permitted assistant features and keep Stop all available.

Everyday tools remain available

Dashboard, journal and counters

Player stats, position and connection, searchable bounded journal, loaded inventory, stack counters, aliases, friends and passive alerts.

Move and equip

Organizer/restock with desired quantities and return-excess options, protected items, equipment sets and finite move plans that wait for observed changes.

Loot, vendors and crafting

Reviewed property rules, bounded watches, vendor stock/price limits and crafting plans using the current exact dialog and observed outcomes.

Healing and preferences

Manual run/watch controls, selected patients, cooldowns, use-once, per-shard definitions and rotating backup/restore previews. No login credentials are saved by the companion.

Configurable potion and bandage timing

Use Cooldowns for fractional-second manual, item-use or literal journal-started countdowns. Keep a separate profile for each shard's durations and messages. Timing & healing adds fixed or dexterity formulas; fresh ready/failure/interruption messages distinguish outcomes. A local expired estimate does not prove a potion was accepted or a bandage completed. These definitions do not heal, drink, block actions or retry on their own.

Mapping built into the client

Marker libraries and versioned layers appear on the native world map, using your selected shard's data. Compatible CSV, UOAM and Ultima Mapper marker XML can be imported; the historical mapper executable and its external sharing service are not embedded. Custom origins are explicit. Nearby A* previews use only loaded terrain and do not prove an unloaded-world route or start movement. See maps, travel and teams.

JavaScript with a documented interface

The constrained Jint engine supports top-level await and the installed API declarations. Scripts have no filesystem, process, network or CLR access. Their actions use the same checked runner as assistant buttons. Stop all prevents further queued requests; an action already sent to the shard cannot be recalled.

Read the complete scripting guide, 63-page PDF and workflow additions. Historical Python, C#, BASIC, arbitrary Orion programs and assistant DLLs require adaptation. An incomplete migration remains blocked.

Design references

Razor and Razor Enhanced informed editable macros, counters, organizer/restock, equipment, protection and property rules. ClassicAssist informed aliases, dialog waits and separate-window workflows. Orion informed JavaScript-style interaction, target selection and timing ideas. Injection informed named objects and compact command shortcuts. ClassicUO supplies the full GPU scene renderer, native input/gumps/world map and smooth movement foundation. Mapper research informed interoperable marker layers and optional team workflows.

The supplied Orion material is historical client source plus a compiled assistant; it does not provide the assistant's source. The archive named ultima-mapper is an Ultima IV viewer. UO marker-format support and native map tools were implemented against the relevant Ultima Online formats rather than loading that viewer into the client.

Testing and practical limits

Automated tests use isolated state, loopback connections, bounded script engines and actual WPF/native handlers. A network-fenced rendering/capture fixture stayed near 60 FPS. NVIDIA hardware encoding was tested; Intel/AMD are probed on your machine. These controlled results are not a new live-shard movement or crowded-scene benchmark. Missing world data, properties, health and OS GPU counters remain unknown.

Test your shard's movement, object clicks, gumps, targets, travel messages and a short clip. Download the unsigned preview from the application page; background website checks and explicit verified downloads are described in Automatic updates. No game assets, accounts, saves, credentials or private logs are included.
