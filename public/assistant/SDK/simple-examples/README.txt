UO Assistant 0.5.0 - Simple Scripts

Import these .uosimple files on Script tools and use Simple Scripts to edit and run them. Their export header retains the recipe run limit. Choose an object in game to save names used by each recipe. The Invicta tree recipe needs an equipped axe saved as lumberAxe and an unmounted character. It has a 30-minute maximum; other recipes have a one- or five-minute limit. JavaScript remains in SDK/examples. Read the matching beginner guide. Nothing runs automatically.
