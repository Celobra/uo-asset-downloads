Get started in four steps.

  1. Install Studio. Close an older Studio instance first. The installer detects a previous installation and reuses its location for an upgrade.
  2. Create a shard profile. Choose your extracted Sphere scripts and a working copy of your UO game-data folder.
  3. Explore an existing asset. Search a definition and inspect its art, animation, references and script.
  4. Try one workflow. Import or preview something small, review the files and keep a backup before saving.

The community installer is not code signed. Check that you are downloading the release linked here. Server-specific gameplay requires a separate test.

Looking for the source?

The source archive is separate from the ready-to-run installer. It contains application code, tests, public documentation and Windows build definitions.

It excludes development environments, private project paths and profiles, game data, accounts, saves, test output and release binaries.

Running or building from source

Use x64 Python with Tk support, install the listed requirements in your own virtual environment and run desktop_app.py. The included source README explains the checks and optional Windows installer build.

Third-party dependencies retain their own licenses and notices. The source download is for people who want to inspect or build the application; most users should choose the installer above.

A few things to know.

Do I need ClassicUO or Sphere running to use Test Scene?

No. The visual scene is inside Studio and reads the linked artwork. It does not simulate Sphere gameplay or replace final in-game testing.

Does Studio include Ultima Online’s game files?

No. Bring your own compatible client data and, for script workflows, your own Sphere scripts. The website examples show demonstration projects.

Can I upgrade without uninstalling first?

Yes. Close Studio and run the new installer. Its stable application identity and previous-install detection are designed to update the existing installation.

Will generating a world overwrite my current map?

No. World generation exports a new folder. Deployment, matching client/server map dimensions, patches, regions and spawns remain deliberate separate steps.

Do the equipment bonuses work on every server?

The presets target Sphere X. Server combat configuration, caps, custom events and loot rules determine the final behavior. The generated scripts are editable starting points.
