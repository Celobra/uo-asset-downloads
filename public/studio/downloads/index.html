Get started in four steps.

  1. Install Studio. Close an older Studio instance first. The installer detects a previous installation and reuses its location for an upgrade.
  2. Choose your starting task. Home opens before any folder setup. For imports and scripts, choose your working client data and server folders; animation-to-VD conversion can start immediately.
  3. Start in Simple. Choose Import Tiles, Import Statics, Import Gumps, Import Animation or Import Mounts on Home. Import artwork in the sidebar keeps these choices together; All tools groups every workflow by task.
  4. Try one workflow. Choose your files, hover for help and check the preview. Review the proposed save; switch to Advanced for detailed choices.

The community installer is not code signed. Check that you are downloading the release linked here. Server-specific gameplay requires a separate test.

A newer version?
Install when you are ready.

Install 0.32.3 or newer once to receive the updater. Studio checks this website after startup in the background and offers a newer stable version when one is available. Choose Later to keep working, or use Updates > Check now when you want to check again.

The update offer links to the release notes. Choose Download & install… to begin. Follow its progress and use Cancel download before installation. Clear Check for updates when Studio starts in Updates to disable startup checks; the choice is remembered across profiles and manual checks remain available. Studio checks the completed installer’s size and SHA256 against this website’s release record before it offers to run it.

Your work stays under your control

Save or resolve pending changes before closing Studio for installation. The same installer upgrades the existing application and retains your profiles. Your client data, scripts, accounts and world saves are separate from the application update.

If the website is unavailable or you are offline, Studio keeps working. The installer above remains available for a manual update, including older versions that do not have the new updater.

A few things to know.

What changed for ModernUO armor, mounts and large ZIP packages?

Import complete armor sets and native mounts with a ModernUO, RunUO or ServUO profile. Checked source and free-space inventories are shared within the current operation, then the files are checked again before the proposal is accepted. Native occupancy, queued reservations, changed files and explicit replacement review remain enforced. Loading shows the active step and elapsed time; known steps show real counts. Nested choices keep complete pieces separate and explain skipped packages. ModernUO remains a preview generation target. C# source browsing stays read-only; C# graphic-reference analysis is unsupported. Representative generated classes compiled against actual server/content assemblies and native serialization generation; this is not a full server rebuild or gameplay test. Compile and test the generated source, equipment and riding on the receiving shard.

Can I open RunUO, ServUO or ModernUO source?

Choose Sphere, RunUO, ServUO or ModernUO in Project Setup. Server roots, Scripts directories, ModernUO UOContent projects and supported source ZIPs are recognised. C# files appear in Script files for reading; Sphere definitions and editing retain their own workflow. C# code is not parsed as Sphere definitions or interpreted for graphic references. Native assets, client mappings and queued reservations remain checked; verify any IDs used only by C# code. Compile and test generated source on the receiving server. ModernUO generation remains a preview.

Can I import artwork without generating a script?

Yes. Keep Artwork only selected above the item, effect or ordinary body import tabs. Review artwork prepares the native client changes. No new server script, resource registration or body mapping is requested. Choose Artwork and server script explicitly when needed; complete mounts and equipment retain their required links.

Can I play and export animated items or effects in Animations?

Yes. Choose Animated items & effects and double-click a result. Play/Pause and Save GIF stay in Animations with native AnimData frame order. Export frame saves the shown frame. Preview in Test Scene is optional. Preview/GIF timing uses selected settings; native timing metadata and body VD exports remain separate.

How do I browse animations without knowing a creature ID?

Open Animations and use All animations. Body animations lists available client MUL/UOP entries; search IDs or names, then double-click a row or press Enter to preview. Animated items & effects lists native AnimData artwork for direct playback and GIF export in Animations; Preview in Test Scene is optional. Definitions are optional labels. Physical source previews and routed body VD exports are distinguished.

How do I avoid overwriting graphics used by existing scripts?

Inspect Asset spaces thumbnails, states and hover details. Automatic placement excludes recognized native data, metadata, indexed script references, client mappings and queued reservations. For a deliberate replacement, read View graphics review details and select the unchecked exact confirmation. Keep a backup starts enabled. Changed inputs require fresh review; restored sessions require approval again. Whole animation footprints and linked mount IDs are protected separately.

Why did reviewing one region complain about another region’s boundaries?

Version 0.33.10 preserves exactly unchanged loaded definitions before validating your edits. Unrelated unsupported boundaries no longer block a valid region review. Changed and new regions still need 1–256 boundary rectangles and valid properties. Errors identify the affected region and source file; preserving an untouched definition does not repair its geometry.

Why does a tile ZIP contain images Studio cannot import?

Choose Import Statics, keep Include subfolders enabled and use Open ZIP. Studio loads compatible individual tiles and lists unusable overview sheets or images in the View skipped files... report. Read the loaded and skipped counts before reviewing IDs and TileData. Static packs allow up to 4096 compatible still tiles within the existing size budgets. Direct Choose images keeps its 256-file cap; native animated statics keep their 64-frame limit. Studio does not split sheets or infer collision or ladder properties.

Where can I see what I recently imported or scripted?

Open Recent activity in either mode for the latest 100 completed imports, script saves, exports and workshop saves. Search the list, select a row for its project/time/files and use Open affected folder. History begins after the upgrade, survives restarting Studio and stays on this computer. Previews, cancelled/failed work and queued-only changes are excluded.

Can I add new definitions to an existing Sphere script?

Yes. In Save script choose Add to existing script, Browse to a .scp inside the active scripts folder and review the complete resulting file. Its original definitions/comments and encoding are retained. New folder stages a subfolder for a new script until the reviewed save. C# targets retain new separate .cs files. Content packs reject existing-file appends; choose New script for portable bundles.

Can an armor set use one Sphere script file?

Yes. In Complete armor set choose One file for whole set with New script and its shared folder/filename, or Add to existing script and Browse to a Sphere .scp. Review complete set shows the complete resulting file before Save or Queue changes. One file per piece remains the default. Each piece keeps its own wearable definition; C# targets retain separate .cs files.

How do I import an armor download with several piece folders?

Open All tools → Complete armor set → Open ZIP and select the archive directly. Check the detected set and piece count, select the intended set and choose Add whole set. For extracted files, use Open set / collection folder and choose the outer folder containing its piece folders and manifest.json. Review complete set keeps the existing fresh-destination and save checks. There is no need to select each piece folder separately.

Can I use every tool in Simple mode?

Yes. All tools and Ctrl+K open the complete tool library. Select Advanced to reveal manual formats, IDs, alignment and replacement settings.

Which artwork import should I choose?

Tiles is for floor, wall and roof item art; Statics is for placed items and props. Gumps opens PNG/BMP interface art. Animation opens a VD, GIF, frame sequence or supported ZIP, and Mounts opens the mount animation workflow with its packaged source, linked icon and server settings. These named choices are on Home and Import artwork in both Simple and Advanced. Use All tools for the other imports and specialist workflows.

Why did a tile-pack preview cause an artwork-limit error?

Assembled layout images can be too large or dense for one native item-art slot. Folder and ZIP imports now skip folders named previews by default and prefer PNG over a matching BMP alternative. Check the list before review and use Remove selected for any unwanted grid. Advanced can restore the excluded choices before reopening the source; Choose images still accepts explicitly selected files. Studio retains source dimensions and native format limits.

Can I save all directions of an existing animation body?

Open Animations, enter the body ID, choose Source Auto and Load body, then Save entire body as .vd. Native MUL bodies retain all available actions and stored facings. Supported UOP ANIMAL bodies produce a standard Animal VD plus a complete ZIP retaining all source groups and mapping instructions. A separate riding VD is included only when an available mapped riding mode exists. Native MUL source gaps are reported. UOP export stops before saving if any source group has a completely blank stored facing. Archival 35-action files are preservation containers rather than ordinary Animal imports.

Does one GIF make a complete creature VD?

No. Save sequence as .vd creates one action and stored facing. Convert body folder to .vd includes the stored sequences present in that body folder. Supply the required movement and riding actions before importing a creature or wearable.

Do I need ClassicUO or Sphere running to use Test Scene?

No. The visual scene is inside Studio and reads the linked artwork. It does not simulate Sphere gameplay or replace final in-game testing.

Does Studio include Ultima Online’s game files?

No. Bring your own compatible client data and, for script workflows, your own Sphere scripts. The website examples show demonstration projects.

Can I upgrade without uninstalling first?

Yes. Close Studio and run the new installer. Its stable application identity and previous-install detection are designed to update the existing installation.

Will generating a world overwrite my current map?

No. World generation exports a new folder. Deployment, matching client/server map dimensions, patches, regions and spawns remain deliberate separate steps.

Do the equipment bonuses work on every server?

Choose Sphere X, official RunUO 2.x, ServUO pub57 or the ModernUO preview when generating a new script. ModernUO still needs full native compilation and shard testing. Expansion rules, combat configuration, custom events and loot rules determine the final behaviour. The existing source editor remains Sphere-specific.
