NEW IN 0.33.3 / OPEN DOWNLOADED PACKAGES

Choose the ZIP.
Bring the content together.

Open supported armor, equipment and animation downloads directly in their Studio workflow. Check what the package contains, select the intended source and continue through the normal preview and review.

A complete armor set

Complete armor set → Open ZIP detects the sets and their piece counts. Select a set, choose Add whole set, then Review complete set.

One wearable piece

Clothing or weapon → Open piece ZIP loads its inventory icon, equipment VD and male/female paperdolls together. Multi-piece downloads belong in Complete armor set.

The intended animation

Body animation Open ZIP offers a VD, GIF or frame sequence. Mount Open ZIP requires a native VD. Select the intended source when several are offered; unrelated animations stay separate.

Retain export metadata

Open sequence ZIP, Convert body ZIP to .vd and Reimport body ZIP in the animation workshop handle supported exports and their origins. Mount icons have Choose image from ZIP.

Loading prepares the source. Client and server files change through the existing reviewed save. An archive does not create missing movements or divide a whole-suit VD into independent pieces.

NEW IN 0.33.1 / ANIMATION FOR MORE THAN CHARACTERS

Moving items.
Spell and visual effects.

Choose Import Animation, then choose what your frames are for. Studio opens the matching workflow with its preview and reviewed save.

Animated items

Import a GIF or ordered PNG/BMP frames for moving objects and decorations. Native item animation starts enabled, including when loading a frame folder or ZIP.

Spell / visual effects

Import fire, water, auras and other frame effects as native animated artwork. Add an optional server visual function when wanted; combat rules remain deliberate server work.

Body / character animations

Use a compatible VD, GIF or ordered frames in the native body-animation layout. A sequence supplies one action and stored facing; missing movements are not created.

Mounts / rideable objects

Keep the existing mount body, shrink icon, riding-memory and server workflow. Check its required poses and mappings before distribution.

To share animated item/effect artwork, queue the reviewed art, TileData and AnimData together, then use Content packs → Export pending bundle before saving the queue. Its .uoasset is a ZIP container for supported changes and linked Sphere scripts. Native body animation uses .vd.

NEW IN 0.33.0 / YOUR EVERYDAY WORKSPACES

Build, edit and check
with fewer interruptions.

Keep the five direct artwork imports and familiar reviewed saves. The tools you use next now offer clearer editing and inspection controls.

Design and test gumps

Pick native client artwork, arrange layers, snap and align controls, then use full Undo and Redo. Test / Interact checks pages, inputs and reply IDs locally before server testing.

Edit an image in your editor

NEW IN 0.32.1 / SHARE THE WHOLE BODY

Choose a body.
Save its animation set.

One visible save button

In Animations, enter the body ID, keep Source: Auto, click Load body, then Save entire body as .vd…. The current preview does not limit the exported actions or facings.

Native data and complete UOP bundles

MUL bodies retain their full native action table. Supported UOP ANIMAL bodies produce a standard Animal VD plus a complete ZIP with riding animations when present, archival source-group VDs, mapping JSON and instructions.

Know what was included

Five stored facings provide eight display directions through UO mirroring. Native MUL source gaps are reported. UOP conversion requires all five stored facings in every source group and stops if one is blank. Empty bulk scans now say No files exported and explain the selected range/source.

ONE ASSET, ALL ITS CONNECTIONS

Keep the creative work moving.

An item is more than a picture. It may need an inventory icon, animation, a paperdoll image, TileData, sound and a script. Studio lets you work on those connections together.

Select a definition and follow its artwork, related files and references. Import a new appearance, check how it moves, give it gameplay properties and review the changes before saving. You spend less time moving between disconnected tools and more time making the thing you imagined.
