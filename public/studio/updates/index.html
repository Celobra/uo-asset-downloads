v0.30.126 September 2026Latest version

Legacy UOP maps load correctly in Map Regions

Improved

  • Standard facet sizes are detected automatically, including 6144 × 4096 and 7168 × 4096 Britannia maps; custom maps retain manual dimensions.
  • Loaded dimensions are displayed above the terrain preview; the 68-page guide explains map loading.

Fixed

  • Corrected legacy UOP terrain chunk addressing, fixing the incorrect map-dimensions error for map0LegacyMUL.uop and other standard maps.
  • Accepted the standard optional trailing padding block while retaining checks for missing, truncated or mismatched terrain data.
  • Cancelling custom dimensions keeps the current preview and its coordinate scale unchanged.

450 unittests passed. All six standard client-map overviews and independent terrain samples were checked without changing the inputs. Packaged launch remains unverified; source runtime, GUI, frozen archive and installer compilation passed.

v0.30.026 September 2026

A redesigned workspace and Sphere Map Regions

Added

  • Home task cards, permanent editor navigation and a searchable All tools page with 26 workflows.
  • Map Regions for Sphere: select, draw, move, add and remove AREADEF / ROOMDEF boundaries.
  • Guarded, safe, spell, recall, gate, teleport, PvP and other region-rule controls with reviewed script saves.
  • Appearance page with ten themes, Standard/Larger text and a panel-layout reset.

Improved

  • Editors remember optional Definitions and Script files panels; save and profile controls are grouped.
  • Tile imports now separate artwork previews from properties and animation; equipment stats use a compact layout.
  • The complete PDF and offline guide now cover 33 chapters across 68 pages.

Fixed

  • Restored and switched editor layouts keep useful panel widths on smaller windows.
  • Region saves preserve custom tags/events and encoding, with script conflicts checked before writes.

Map Regions targets Sphere only. Terrain is read-only; custom events, region ordering and final guard/travel behaviour require shard testing. Keep a covering world region and stop Sphere before saving. Packaged executable launch remains unverified; source runtime, GUI, frozen archive and installer compilation are checked.

v0.29.026 September 2026

Static tile packs, ModernUO preview and better worlds

Added

  • Import static walls, floors and items from PNG/BMP folders or ZIPs, with optional subfolders, sorted previews and reviewed free-slot placement.
  • ModernUO preview script target for official 0.15.6.198, using native generated serialization and UOContent destinations.
  • Find area shortcuts for coast, forest, desert, snow, mountain, volcano and path previews.

Improved

  • Smoother biome boundaries and distance-aware river routing in generator version 2.
  • Tree spacing accounts for canopy size while keeping trunk and canopy pieces paired.
  • World exports report missing shoreline-art matches; the guide covers the new imports and target limits.

Fixed

  • Changed world settings now mark the preview outdated and require regeneration before export.
  • Non-dyeable C# armor no longer generates an unsupported Dye override.
  • Script workshop instructions and world summaries fit better in smaller windows.

ModernUO passed source and syntax checks; a full ModernUO build and shard testing remain required. Existing definition, sound-link, removal, house/deed and world entrance script workflows remain Sphere. Older world settings regenerate with the new rules; keep previous native exports for exact layouts.

v0.28.025 September 2026

Sphere, RunUO and ServUO scripts

Added

  • Choose Sphere, official RunUO 2.x or ServUO pub57 when importing monsters, mounts, items, effects, clothing and weapons.
  • Choose one script target for a complete armor set, including whole-folder imports.
  • Generate scripts for artwork already installed through Workspace → Workshops → Generate server script.
  • C# templates include spellcasting, healing, taming, triggered effects, temporary summons, equipment bonuses and weapon hit effects.

Improved

  • Review the generated source, destination and GM creation command before saving. Check existing filenames and C# class names, including combined or restored queues.
  • Updated the complete guide to 65 pages with target-specific export instructions.

RunUO and ServUO both use C#, with separate templates for their APIs. Existing definition editing, sound-link editing, removal, house/deed and world entrance scripts remain Sphere workflows. Generated scripts still need gameplay testing on the chosen server.

v0.26.020 September 2026

Dungeons, caves and equipment bonuses

Added

  • Reserve a black off-world area for connected stone dungeons and natural caves.
  • Generate graded cave openings in the main map, paired interior locations and optional two-way Sphere entrance/return scripts.
  • Follow entrances and return locations in World Explorer.
  • Add weapon and armor stat bonuses or penalties, Luck, five resistances, combat modifiers, skill bonuses and percentage-based on-hit spells.
  • Copy a piece’s equipment effects to the rest of an armor set.

Improved

  • Real terrain elevation, slightly uneven ground and bounded slopes remain consistent between the explorer and exported map. Sea water stays at height zero.
  • Guide expanded to cover underground areas, sound replacement and equipment effects.

Generated maps are separate exports. Regions, spawns, loot and server activation remain separate work; Test Scene does not execute combat scripts.

Custom mounts, layout and removal fixes

  • Handle mount remnants from earlier partial removals, including linked figurine aliases, while retaining shared or externally referenced content.

Several follow-up builds kept the 0.20.2 version number. Their verified changes are collected here; unrelated references still require review.
