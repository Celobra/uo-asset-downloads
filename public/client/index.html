EXISTING CLASSICUO FOLDER

Close. Copy. Play.

  1. Close ClassicUO and back up its folder. Keep the backup until you have checked the replacement on your shard.
  2. Extract the ZIP. Open the ClassicUO folder inside it. Copy all its contents into your chosen ClassicUO folder, replacing matching program files.
  3. Start ClassicUO.exe directly. The ZIP preserves your existing settings and profiles. Keep all the supplied DLLs and subfolders.

Starting from an empty folder?

Extract the complete ClassicUO folder and open Configure ClassicUO.cmd. Choose your UO game-data folder, enter the shard address, port and UO client version, then save.

Close setup and launch ClassicUO.exe. Setup refuses to overwrite an existing settings.json.

Launchers may overwrite custom program files. Existing assistants need their own compatibility check.

OPTIONAL · SPHERE STAFF

Player features need no scripts.

GM Tools requires the server to confirm PLEVEL 4 or higher. Without the access helper or a valid reply, staff tools stay locked. Ordinary play, Workspace and the health bar continue to work.

Server administrator setup

The ZIP includes two optional helpers under ServerHelper:

  • cuo_staff_access.scp supplies the account-level check.
  • cuo_workshop.scp supplies server-side staff inspection and Workshop actions.

Install both once in the server's active script tree and resource list, then use the server's normal resync or restart procedure. Follow ServerHelper/INSTALL.txt or the PDF. These files belong on the server, not in the player's game-data folder.

Server permissions still control commands. Access is rechecked and closes on revocation, timeout or disconnect. Other server engines need compatible helpers. UO Asset Studio and its optional bridge are separate downloads.
