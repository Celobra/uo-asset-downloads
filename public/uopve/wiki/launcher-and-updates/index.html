Getting started

Launcher, updates & repair

Keep your game files current, repair an installation and use optional Razor.

Upgrade an earlier launcher

Download and run the current UOPvE-Setup.exe once to upgrade the launcher itself. Release 1.0.3 opens the game without an extra command window, with or without optional Razor.

The launcher continues to check game files when it opens and before PLAY. Existing 1.0.2 players keep the same game files; this launcher update does not require downloading them again.

Automatic game updates

The launcher checks for the latest game release when it opens and again before PLAY. It downloads missing or changed release files, including new maps, while keeping unlisted player files.

Close ClassicUO before an update. If the game is already open, the startup update pauses until it can safely apply the files. Keep the launcher open while a download is running.

Game files and maps update through the patcher. A new launcher executable is distributed through a new installer release.

Verify or repair

Choose Verify / repair if release files are missing or appear damaged. The launcher checks their sizes and SHA-256 checksums and replaces files that differ from the published release.

Open Settings to check the installation folder or choose View log when troubleshooting. If an update fails, check your connection, make sure the game is closed and try Install / update again.

Connection settings

The default shard address is live.uoassets.com, port 2593. The configured client data version is 7.0.20.0.

Use the UO:PvE launcher to open the game with its dedicated settings profile. Enter account details in ClassicUO; the launcher does not store your game password.

Optional Razor

Leave Launch with Razor unchecked to play with ClassicUO alone. Enable it if you want the compatible Razor Community Edition plugin included in the client release.

Import files is an alternative to downloading: select an existing Ultima Online client folder that contains game data and ClassicUO. Import into a new or empty game folder.

Uninstall the launcher through Windows Installed apps. Your game folder and player settings are retained.

Guidance follows the current UO:PvE configuration. Use the in-game panels for the latest requirements and rewards.
