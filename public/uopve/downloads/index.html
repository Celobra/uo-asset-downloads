FROM DOWNLOAD TO PLAY

Three steps into the realm.

  1. 01

    Install the launcher

    Open UOPvE-Setup.exe and choose Install UO:PvE. Setup installs for your current Windows user and opens the launcher.

  2. 02

    Let your world download

    Keep the launcher open while it downloads ClassicUO and the game files. Check the game folder in Settings. Leave Launch with Razor unchecked unless you want to use the included plugin.

  3. 03

    Choose PLAY

    Once installation completes, choose PLAY and enter your account details in ClassicUO. The default connection is live.uoassets.com:2593.

Already have a compatible client?

Use Import files and select the folder containing your game data and ClassicUO. Import into a new or empty game folder.

READY FOR THE NEXT UPDATE

Keep your world current.

To upgrade an earlier launcher, download and run the current UOPvE-Setup.exe once. The launcher checks for new game files and maps when it opens and before PLAY. Close ClassicUO before applying an update. Verify / repair can restore missing or changed release files.
