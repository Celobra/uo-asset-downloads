7 October 2026Client release

UO:PvE 1.0.3 opens the game without an extra command window

PLAY opens the custom ClassicUO game window directly, with or without optional Razor.

  • Run the new UOPvE-Setup.exe once to upgrade an earlier launcher.
  • All 790 game files are unchanged from 1.0.2; existing players do not need to download them again.
  • The custom client, UO:PvE login artwork and optional Razor remain available.

7 October 2026Client release

UO:PvE 1.0.2 adds the custom client and login artwork

ClassicUO Standard Update4 uses the branded UO:PvE login screen, with optional Razor and more reliable updates.

  • Optional Razor Community Edition 1.9.77.0 includes matching GPL source and a compatibility build recipe.
  • Verified downloads survive interruptions and are reused on retry; transient GitHub failures receive bounded retries.
  • Repeated game-port status probes were removed to avoid triggering the server connection limit.
  • Existing player profiles and unlisted files are retained. Close ClassicUO before updating.
  • Branded login-screen and optional Razor startup checks passed; player account login was not tested.
Read the 1.0.2 release notes →
7 October 2026Client release

UO:PvE 1.0.1 is available

The Windows installer, patcher and launcher are available through the public client release.

  • Install ClassicUO and the game files through the dedicated UO:PvE launcher.
  • Receive updated game files and maps when the launcher opens or before PLAY.
  • Verify and repair release files, or import an existing compatible client.
  • Launch with ClassicUO alone or enable the included optional Razor Community Edition plugin.
