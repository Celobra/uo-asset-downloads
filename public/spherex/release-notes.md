# SphereX 2026.10.16-preview

16 October 2026. Windows x64. Unsigned custom SphereServer X Nightly preview.

This first standalone website release packages the existing 8 October native source with a fresh stock script library and blank accounts and saves. It includes the coloured console, administration map, character tracking, available route overlays and permission-checked Owner tools. The native UTF-8 empty-line and disabled-facet corrections are retained.

A clean build removes embedded private compiler paths. No gameplay source changed for publication. The matching complete source archive, source inventories, build instructions, licences, checksums and setup guide accompany the Windows ZIP. Supply your own compatible UO client data. Optional custom NPC, courier and faction-patrol examples are not installed in the fresh world.

The public executable passed the existing console-tools test suite and isolated fresh-world, Owner setup/login, save and restart checks. Archive integrity, empty distributed account/save files, source correspondence and privacy were checked.

Known small-window layout and Pause problems, costly searches, activity recording gaps and native pathfinding work remain. The previous audit's proposed improvements are not implemented here. There is no new production-load, receiving-system or multiplayer-gameplay validation, and old benchmark results are not measurements of this public rebuild.
