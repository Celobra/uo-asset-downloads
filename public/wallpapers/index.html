CHOOSE HOW TO USE IT

A video, or a live page.

Video: download the MP4 to watch it, or add it to a live-wallpaper application that supports looping video. Windows needs a separate application to use animated desktop backgrounds.

Offline live version: extract the complete ZIP and open index.html in a modern browser. Keep wallpaper.js and the assets folder beside it. The package runs offline and includes its two original illustrations and a setup guide.

For desktop use, add the extracted page to a compatible web-wallpaper application. No wallpaper application is bundled or installed. This delivery has been checked in a browser; applying it to the system desktop remains untested.
